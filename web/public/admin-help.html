GuildPilot Admin Command Guide

Live command reference aligned with the current module-first architecture.

Command Taxonomy

  • Canonical module commands: /verification, /governance, /treasury, /wallet-tracker, /invites, /nft-tracker, /token-tracker, /aiassistant, /minigames, /points, /heist, /config, /moderation.
  • Minigames currently use dedicated commands and are all entitlement-gated under the minigames module.
  • Canonical public API: /api/public/v1/*.

Portal-managed modules

  • Welcome & Onboarding: join messages, CAPTCHA, assets, presets, and analytics.
  • Auto Messages: recurring announcements, schedules, tests, and delivery audit.
  • Telegram Bridge: Telegram-to-Discord mappings, media forwarding, tests, and delivery audit.
  • Guild Guard: an owner-friendly Community Safety Center with protection presets, wallet-scam language detection, disguised-link checks, dangerous file and QR-code inspection, Campaign Radar, Account Trust, grouped incidents, bulk response, private member reporting, manually reviewed cross-community domain intelligence, protection analytics and tuning recommendations, staff impersonation monitoring, recoverable raid response, and one-click domain blocking.
  • Support Tickets: categories, forms, panels, transcripts, open-ticket review, and automation.

Configure these features from Modules in the portal. They do not require a dedicated slash-command family.

Verification

  • /verification status
  • /verification wallets
  • /verification refresh
  • /verification quick

Admin: /verification admin panel|export-user|remove-user|export-wallets|token-role-add|token-role-remove|token-role-list|role-config|actions|og-view|og-enable|og-role|og-limit|og-sync

Network-aware rules: Configure Solana collection/SPL rules or Ethereum, Base, Robinhood Chain, Polygon, Arbitrum One, and Optimism ERC-721, ERC-1155, and ERC-20 rules in Modules → Identity / Verification. Existing roles are preserved when an EVM RPC check is unavailable.

One EVM identity: A verified EVM address is checked across every configured EVM network. Members do not need to reconnect the same address separately per chain.

Engagement

/points balance|leaderboard|history|daily|shop|redeem|admin

AI Assistant (Pro)

/aiassistant ask|status|briefing

Portal controls support provider/model routing, allowlists, passive/mention channel modes, confidence thresholds, and daily recap scheduling.

Advanced controls include memory mode, multi-persona profiles, per-role request/token limits, guarded action suggestions, ingestion jobs (URL/Markdown/PDF/Discord channel), and unresolved-topic analytics.
